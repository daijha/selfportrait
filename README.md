# **About This Project**

This is a small, desktop‑first project I created to stay consistent with my coding practice while also having a little fun. I wanted something light, personal, and creative — a space where I could play with layout, styling, and hover‑based interaction without the pressure of building a full application.

I built the entire page using **HTML and CSS**. Along the way, I also used this as an opportunity to practice drawing simple icons in Figma and exporting them as SVGs. Each icon on the page represents one of my interests, and hovering over an icon reveals a short description connected to that part of my life.

This page is designed for **wide‑screen viewing**. Because the experience relies on hover interactions and a spacious layout, it works best on a laptop or desktop rather than a mobile device.

To explore the portrait, simply hover over each icon to reveal the text.

Enjoy <3
